Prompt Estruturado para Agente de IA (Antigravity)
Role: Atue como um Engenheiro de Software Sênior especializado em Backend e Engenharia de Dados.
Task: Realizar uma auditoria técnica completa no código da minha API de portfólio para elevar sua maturidade de "Aprendizado" para "Nível de Produção".

Contexto do Projeto:

Tech Stack: FastAPI, PostgreSQL, SQLAlchemy, Docker, Redis, JWT, Pytest.

Objetivo do Portfólio: Demonstrar domínio em Clean Code, escalabilidade e boas práticas de arquitetura.

Diretrizes de Análise (Checklist de Auditoria):

Design de API: Avalie se os endpoints seguem os princípios RESTful, uso correto de status codes e versionamento.

Arquitetura de Dados: Verifique a eficiência das queries, uso de ORM vs SQL puro, e se há tratamento adequado para concorrência/transações.

Segurança e Validação: Analise a implementação de Pydantic/Schemas, sanitização de inputs e proteção contra injeções.

DevOps & Observabilidade: Verifique se o código facilita a conteinerização (Docker), se possui logs estruturados e suporte para healthchecks.

Qualidade de Código: Identifique débitos técnicos, complexidade ciclomática alta e violações dos princípios SOLID.
